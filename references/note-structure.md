# 结构选择与模板

## 三种结构，按讲时长选

| 场景 | 结构 | 已落地的课 |
|---|---|---|
| 每讲 ≤ 10 分钟、一讲一个知识点 | 章文件夹 → 一讲**一篇** `NN-标题.md` + `assets/` | 高频电子线路（95 讲） |
| 每集 15–50 分钟、一集多个知识点 | 章文件夹 → 讲文件夹 → **多篇正文** + `00-本讲索引.md` + `99-扩展笔记.md` + `assets/` | STM32 入门教程（45 集）、电磁场速成（14 讲） |
| 单讲、要边看边补深度内容 | 讲文件夹 → `01-视频讲解.md` + `02-扩展笔记.md`（SKILL.md 原始双笔记模式） | ESP32 IDF 课程 |

判据是**讲师自己在这段视频里划了几节**。他开场说"本次课包含 1、2、3、4"，那就是 4 篇的骨架，不要按自己的理解重排或合并。

## 时长 → 拆篇数

| 讲时长 | 知识点正文篇数 | 一单派几讲 |
|---|---|---|
| ≤ 6 分钟 | 1 篇 | 6 |
| 6–15 分钟 | 2–4 篇 | 4–5 |
| 15–30 分钟 | 4–6 篇 | 2–3 |
| > 30 分钟 | 6–9 篇 | 1 |

图片：每篇 1–3 张，每讲 3–6 张（>30 分钟的讲可到 8–10 张）。宁少勿滥——连续帧凑数、图注与图不符都是返工点。

## 目录与命名

```text
<vault>/<课程名>/
├─ 00-课程索引.md
├─ 第3章-GPIO/
│  ├─ 00-本章索引.md
│  └─ 3-2-GPIO输出配置/
│     ├─ 00-本讲索引.md
│     ├─ 01-输出模式与寄存器.md
│     ├─ 02-例题与代码骨架.md
│     ├─ 99-扩展笔记.md
│     └─ assets/
│        └─ 3-2-01_输出模式表.png
└─ 附录-全书思维导图/…
```

- 讲号 `章-序`（`3-2`），不是分 P 号——一章可能跨多个 P，也可能一个 P 含多讲。
- 附录用 `chapter: "0"`，目录名 `附录-<主题>`。
- 图片前缀带讲号（`3-2-01_…`），全库唯一，避免不同讲同名图互相覆盖。
- 视频原标题有错字时（「平面电磁场」→「平面电磁波」、「基级」→「基极」），目录与标题用正确叫法，原标题原样保留在 `00-本讲索引.md` 的「本讲信息」里。

## `99-扩展笔记.md` 固定四段

1. **考点清单**：标频考等级 ★★★／★★／★。
2. **公式速查表**：本讲 + 相邻讲会联用的。
3. **易错点**：每条「错在哪 → 为什么错 → 怎么判断」。优先收老师口头强调的坑，其次是符号方向、单位、适用条件这类真实易错处。
4. **典型题**：视频讲过的题给完整步骤；视频没做题就自拟 1–2 道，只用视频里出现过的公式，并标「自拟」。**不得把自拟题写成"老师讲过"。**

## `00-本章索引.md` 三节（各讲完成后由主代理或补写代理填）

- **本章主线**：3–6 行说清本章讲什么、展开顺序、与上下游章节关系；可配一张 `flowchart LR` 知识链。
- **公式速查**：`| 公式 | 含义与适用条件 | 出自 |`，「出自」写讲号（`5-2 例题六`），只收各讲正文确实出现过的。
- **易错点**：5–10 条，跨讲合并同类项（例如"有限性淘汰发散项"这类判据在镜像法、柱坐标、球坐标里各出现一次，合成一条更好背）。

## `00-课程索引.md`

课程信息（BVID、UP、分 P 数、总时长、归档方式）+ 进度 + 章节导航 + 全部讲次表 + **考前复习路线**（三遍过法：框架 → 公式默写 → 易错与例题）。速成课/考试导向的课一定要写复习路线，这是用户实际会反复打开的那一屏。

## 一句话总结与「待核对」

- 每篇正文都要有 `> [!abstract] 一句话总结`；写不出来说明这节没读懂，回去看转写。
- 口述与幻灯片矛盾、画面看不清、课件疑似笔误 → 标「待核对」，写清两种读法与判断依据，考试口径注明"以教材/讲义为准"。不要为了整洁删掉这些标记。

## 编程课的验证口径

代码类课程常说"代码要可编译"。先确认本机是否真有编译器（gcc/MinGW/cl 或对应语言工具链）：

- **有**：真的编译并运行一次，笔记里可以写「已验证输出为 …」并附实际输出。
- **没有**：**不要声称编译验证过**。改成「按画面逐字照录」，逐格比对源码与运行输出截图；幻灯片上的片段标「幻灯片原文」；需要完整可运行版本时放进 `99-扩展笔记.md` 并标「补充」。

把没做的事写成做过，是这套笔记最危险的失败模式——读者会照着抄。
