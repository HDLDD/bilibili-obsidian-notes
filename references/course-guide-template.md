# 课程级 GUIDE 模板（每门课一份，放进该课工作目录）

派子代理时，任务书第一句就是"先完整阅读 `<work>/NOTE_GUIDE.md`"。这份文件是**该课专属**的口径手册——格式规范、命名、拆篇数、ASR 纠错表都写在这里，代理只需读它 + manifest，不用每次重讲规则。

下面是模板，尖括号处按本课填写。整课流程本身不用抄进来（在 skill 的 `batch-pipeline.md`），这里只放**这门课特有的东西**。

```markdown
# <课程名> 笔记生成指南

## 目标
为分配到的每一讲生成一个讲文件夹：多篇知识点正文 + `00-本讲索引.md` + `99-扩展笔记.md` + `assets/`。
**只改自己负责的讲，不要动章索引/课程索引，也不要动别的章节。**

## 路径
- 工作目录：`<work>`
- 清单：`<work>/manifest.json`（字段：chapter / folder / seq / slug / part / part_title /
  lesson_folder / lesson_path / duration / work / url）
- 抽帧：`python <skill>/scripts/course_prep.py keys --work <work> eXX "秒1,秒2"`
- Vault 根：`<vault>/<course_dir>`
- 参考成品：`<vault>/<course_dir>/<某章>/<某讲>/`（挑一章写得最规范的当样板）

## 单讲流程
1. 在 manifest.json 找到负责的 slug，记下 part / work / lesson_path。
2. `eXX/transcribe/transcript.txt` 已就绪，**不要运行 acquire**。缺素材就报告，不要自己采集。
3. 通读转写，先按下面的纠错表校正术语，再动笔。
4. 看 `eXX/frames/overview_*.jpg` 规划分节（每格 <15> 秒），挑关键画面。
5. 抽帧 → 复制进本讲 `assets/`，命名 `<slug>-NN_说明.png`，每篇 1–3 张、每讲 3–6 张。
6. 按讲师自己划的小节拆正文，篇数按下表。
7. 写 `00-本讲索引.md`（知识点表 + 视频进度 + 本讲速记）与 `99-扩展笔记.md`（四段固定结构）。

## 拆篇数量
| 讲时长 | 正文章数 |
|---|---|
| ≤6 分钟 | 1 |
| 6–15 分钟 | 2–4 |
| 15–30 分钟 | 4–6 |
| >30 分钟 | 6–9 |

## 本课特别注意
- <结构特例>：例如「P7 原标题写作『电磁场与电磁波-静态场(2)』，实为第 5 章续集，
  目录用『5-2 静态场的解析方法（2）』，原标题保留在本讲索引里」。
- <命名口径>：例如视频说「平面电磁场」，教材与库内统一用「平面电磁波」。
- <内容口径>：例如课件把同轴线 r₁ 定义为外导体半径（与多数教材相反），按课件写并加注判据。
- <高风险小节>：例如「极化旋向判据、边界条件法向/切向归属、子问题与原问题的边界条件区分」。

## 写作要求
- 忠于转写与画面；视频没讲的不写进正文，要补就放 99 并标「补充」。
- 归属四分：幻灯片原文 / 板书 / 口述 / 笔记补充，不要互相冒充；自拟题必须标「自拟」。
- 口述与画面矛盾、画面不清、疑似课件笔误 → 标「待核对」并写清两种读法。
- 公式写清符号含义、单位、适用条件（<本课量纲清单>：E(V/m)、D(C/m²)…）。
- LaTeX；表格里绝不出现裸 `|`（绝对值 `\lvert x \rvert`，wikilink 竖线 `\|`）；
  wikilink 不用 `[[../x]]`，跨讲一律库内全路径。
- 不确定就少写，不要硬编。

## ASR 纠错表（本课实测）
| 转写 | 正确 |
|---|---|
| 麦克斯 / 麦克威 | 麦克斯韦 |
| 坡形亭 / 波形停 | 坡印廷 |
| 实写场 / 十阶场 | 时谐场 |
| 酶质 | 媒质 |
| 曲幅 / 屈幅 | 趋肤 |
| 维星 | 唯一性 |
| <继续补充> | |

## 返回报告
生成的文件清单、每讲图片数、标了「待核对」的位置、`verify_course.py` 的输出首行。
```

维护要点：

- 纠错表是**活文档**。每轮复核发现新的听错术语，就补一行——下一门同类课直接受益。
- 「本课特别注意」是防止代理踩课内陷阱的地方，写具体（哪一讲、哪个记号、什么相反），不要写空泛提醒。
- 参考成品那行很重要：给代理一个真实样板，比写十条规则有效。
