# 踩过的坑：Markdown / Obsidian / Windows 工具链

每一条都是真实返工换来的。写笔记时按这份清单自查，比事后批量修省事；批量修也有脚本（`fix_course_md.py`、`verify_course.py`）。

## 表格里的竖线

Obsidian 的表格按裸 `|` 切单元格，**数学模式内也算**。三种写法都会断列：

| 断列写法 | 正确写法 |
|---|---|
| `\|AF\| > 1` | `\lvert AF \rvert > 1` |
| `\left. \dfrac{\partial\varphi}{\partial n} \right\|_S` | `\bigl.\dots\bigr\rvert_S` 或改写成 `\vert_S` |
| `[[00-本讲索引\|笔记]]` 写成 `[[00-本讲索引|笔记]]` | 表格里的 wikilink 一律转义成 `\|` |

`fix_course_md.py --pipes` 会把表格行里的 `\left|`/`\right|`/`\big|` 换成 `\lvert`/`\rvert`，并把未转义的 `[[a|b]]` 变成 `[[a\|b]]`。已经转义过的不会被二次处理。

**注意别用 `\|` 去"转义"数学绝对值**：MathJax 里 `\|` 等价于 `\Vert`（双竖线范数），`$\|E$\|$ 会渲染成 ‖E‖ 而不是 |E|。绝对值只能写成 `\lvert E \rvert`；`\|` 只用于转义 wikilink 的别名分隔符。

写校验器时注意：统计列数要按**未转义**的竖线切（`re.split(r"(?<!\\)\|", line)`），否则会把 `\|` 误判成断列——这个假阳性在高频课和电磁场课各浪费了一轮。

## wikilink 不支持相对路径

`[[../02-下一节|下一节]]` 在文本编辑器里看着对，Obsidian 里是死链。要么写库内全路径 `[[第5章-…/5-2-…/02-下一节|…]]`，要么只写唯一文件名。

全库每讲都有 `00-本讲索引.md`、`99-扩展笔记.md`，**只写文件名必然歧义**，所以跨讲导航一律用全路径。`fix_course_md.py --links` 负责把 `[[../x]]` 批量改成全路径。

## 中文标点与文件名

- 标题里的全角冒号 `：`、破折号 `—` 与半角 `:`、`-` 混用，会让链接指向不存在的文件（`02-恒等式证明—旋度…` vs `02-恒等式证明-旋度…`）。**文件名与链接逐字一致**，别手敲。
- 正文重命名后，本讲索引表格里的链接要同步；`verify_course.py` 会报"正文未被本讲索引收录"。
- 同一讲出现两个 `05-xxx.md`（一个旧稿一个改名的新稿）是并行代理的常见产物，收尾必须查重号。

## frontmatter 与 H1

`title` 与首个 `# ` 必须一致，否则 Obsidian 标题插件、图谱、搜索三者显示不同名字。批量生成时最容易漂：代理给 H1 加了小节号（`8-1 推迟位的多极子展开（8.1）`）却没改 `title`。`verify_course.py` 把这条列为 HARD。

同理 `part`、`duration`、`source` 要和 manifest 一致；`duration` 统一 `mm:ss`（超过 1 小时也写成 `47:12`、`76:05` 这种分钟制，别一半 `h:mm:ss` 一半 `mm:ss`）。

## Windows / Git Bash 特有

**控制台是 GBK。** `print` 中文会 `UnicodeEncodeError` 或输出乱码——不是数据坏了，是终端。要么设 `PYTHONIOENCODING=utf-8` 并把结果重定向到文件再读，要么直接写文件。

**反斜杠会被 shell/JSON 层吃掉。** 在 Bash heredoc 里写 Python 源码，`"\\right"` 可能变成 `"\right"`，Python 再把 `\r` 解释成回车——写进文件的就是一个 CR 字节，肉眼看不出，表格和公式全废。本会话两次踩到（`\lvert V_{BB}\rvert` 变成 `\lvert V_{BB}<CR>ert`；测试 fixture 里 `\right|` 变成 CR+`ight|`）。
**凡是含 LaTeX 反斜杠的脚本或内容，一律用 Write 工具落盘，再执行。** 不要用 heredoc 拼。

**CRLF。** 代理写的 `.md` 常是 `\r\n`。多行字符串 `replace` 会静默失配。读文件用 `newline=""` 保留原样，逐行处理时先探测换行符。

**`robocopy` 返回 16 不代表成功**（常常什么都没拷）。批量拷贝用 Python `shutil.copytree(..., dirs_exist_ok=True)`。

**`ffmpeg drawtext` 会段错误**（本机 fontconfig 不全）。时间戳靠总览格子的序号换算，别烧字到图上。

## 图片与时间戳

- 图注「视频 mm:ss：…」必须真的是那一帧的内容。代理会按正文推断时间点，结果图与说明各说各话（电磁场课 2-1/03 的"保守性页"实际是电偶极子页）。核验方法：把该秒的 overview 格子或原帧看一眼。
- 竖版/居中图（思维导图）截图会带大片黑边，按白色内容包围盒裁一次。
- 未被任何笔记引用的图要处理：要么补进正文，要么删（删前确认它不是别的讲需要的）。`verify_course.py` 报 `unused_assets`。

## 归属与诚实标记

引用来源分四类，别混：

- **幻灯片原文**——能在画面逐字找到；
- **板书**——老师手写，注意字母小、易误读（把 $\vec C=\vec D+\vec E$ 认成 $\vec G=\vec D+\vec R$ 就是这类）；
- **口述**——只在语音里出现，写成"老师说"，不要写"幻灯片给出"；
- **笔记补充/自拟**——必须显式标注，尤其是自拟题，否则读者会当成考题原样。

口述与画面矛盾时（老师把"电荷守恒"说成"能量守恒"、课件把 5.3.3 印成 5.4.3、把「无散场」印成「无场源」），**以画面为准并标「待核对」**，写明两种读法和判断依据。不要为了好看删掉这些标记——它们是这套笔记可信度的来源。

## 校验器自身的口径

`--asr` 传的是**正则**，逗号分隔。中文没有词边界，两字热词会命中正常词：`解条` 命中「定解条件」。用否定前瞻 `解条(?!件)`，或换更长的词。
